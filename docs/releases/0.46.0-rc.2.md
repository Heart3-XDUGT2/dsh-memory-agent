# 0.46.0-rc.2 · 预发布

本版更新 Echo 的记忆图、独立 3D 星图和审计台。

- **情景记忆和交通节点**：记忆节点保存事件内容，由交通节点连接；交通节点可以彼此相连，形成多跳联想路径。联想是检索线索，不等于新的事实。
- **独立 3D 记忆星图**：从面板打开“记忆星图（独立）”，或进入宿主内的 `/echo/mock/final/memory-star.html`。两类节点可以分别筛选，选中节点可查看内容和连接。
- **更新后的审计台**：从 `/echo/mock/final/index.html` 进入审计，查看轮次的阶段记录及后台事件。没有观测到某一步，不等于它未执行。

这是预发布版。请先用独立数据目录评估，升级前备份已有数据，步骤见[安装说明](../INSTALL.md)。本版的[发布树检查](../TESTING.md)和打包验证是静态检查，不代表已通过宿主实机、浏览器交互、真实模型、跨仓集成或生产迁移验收。
