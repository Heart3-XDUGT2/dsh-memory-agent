## 四、结论:冷硬不是「没听话」,是「听了另一份话」

1. **硬的只有一条:签名语气词 0%。** 前段明写「句尾常带～/嘛/啦/呀」「喜欢用
   嘿嘿/啊哈/嗯哼」,21 句里一次都没出现;「主人」只有 10%。这不是「她忘了」,
   是**尾部的示例压过了头部的形容** —— 模型跟示例走,而四条例句
   (「……哼,知道了。」「你猜。」「嗯,在。刚在想别的事。」「不是,你听我说完——算了,没事。」)
   没有一句带语气词、没有一句叫他。
2. **它跟自己的铁律打架**:铁律说锋利只对恶意挑衅、真心话不许用毒舌挡;战斗版却是
   通用要求。他问「现在感觉怎么样」(真心话),她答「像台被你按了一上午的仪器」。
3. **长度其实达标**(27 字、76% ≤40)——所以「冷硬」不是「话太长」,是
   **每句都以句号收尾的陈述/反问,零温度标记**。要改的是语域,不是长度。
4. **情绪档位的常态读数是低两档**(78% 落在 ≤4),而那两档的原文写着
   「心里基本没什么波澜」「还不至于真的动气或动情」——她每轮都在读「我不想动情」。
5. ~~DSH 窗口里她被任务化,38% 是报账腔~~ —— **撤回**:那 38% 是提取器字段的
   输出格式,她说的话里一个都没有(见第五节)。原计划的 E(改 relay 包装语)
   因此**没有证据支持,已放弃**,只留一条「别复述动作」的防线放在尾部自检里。

### 修订史(第一版错在哪)

- 第一版读 `audit_logs.llm_reply`,按 `tool_call` 分组时没注意:这一列**只有
  `extract` 行有值**(33/33),其余全是 NULL。
- `extract` 行装的是 `judge.py` 的产物:第一行是第三人称摘要(「已回他:「好。你肯问
  这句,就更好了。」」),第二行是内心戏(「——他真照我说的问了…」)。于是:
  - 「中位数 49 字」= 摘要长度,不是她的话;她真正的话是 27 字;
  - 「38% 报账腔」= 摘要的文体(「已回:…」是它描述动作的方式),她说的话里 0%。
- 怎么发现的:我打算改「relay 包装语」时先去代码里找「已回:」是谁写的 ——
  `lib/`、`scripts/`、`astrbot_adapter/` 里**一处都没有**,于是回头查列,假结论当场拆掉。
- 教训(已写进 `scripts/voice-metrics.mjs` 的注释):**先确认「这一列是谁写的」,
  再量。**

于是不只量她的话,也量**她读到的上下文**:

- `npm run check:persona`(会话存档逐字核对):人格**确实送达** ——
  `session-echo-companion` 那条 prompt 共 11,846 字,前段在 **61.8%**、后段结束在
  **77.2%**。Echo 自己的段里她的规则是最靠后的(`persona` 10245 < 快照 10260 <
  `rules` 10275,`lib/turn-snapshot.js:48`)。
- **但紧跟在她规则之后的,是【别处刚说过的】**,而它四条里三条是机器提示词:
  她自己的 extractor 提示词(「你是一个严格的记忆与情绪反思模块…输出一个 JSON 对象」)、
  子代理任务提示词(「只读分析任务,禁止修改任何文件…」)、afaccess 插件的命令安全审查员提示词。

活库口径(`conversation_log` 100 行):**90 行过筛**,其中 **71 行渠道为空**(系统写的)。
按条数:21×extractor 提示词 / 9×子代理任务 / 6×审查员 / 6×「你在为项目 dsh-echo 整理
架构文档素材」/ 5×「你是只读资料提取员」/ 2×「你要**只读**分析一个第三方 DSH 插件包」/
2×「你是只读代码分析员」… **全部渲染成「他:」**,按 `sharedRounds`(4)每轮喂回给她。

→ 也就是说:**「<称呼>刚在别处说的话」读起来是「你是…审查员」「输出一个 JSON 对象」**。
模型跟着最近上下文的语域走 —— 工程腔有一份是这样被喂出来的。而且这些行**排在人格
后段之后**,正好压在她最该被提醒的位置上。

判据修在 `lib/inbound-filter.js`(捕获层、检索取词、`context.js:291` 共用同一份):
显式台账(`你是一个严格的记忆与情绪反思模块` / `你是「Almost Full Access」插件的命令安全
审查员`)+ 「任务指令开头」(`只读任务|你在为项目|你要…只读…`)+ 三条形状判据
(≥80 字 **且** 指令式开头 **且** 前 120 字带动作词 —— 三条同时成立才拒,免得误伤他
的短句)。另补 `background job ` / `background subagent ` 两类收尾通告。
