## 2. 五条可以直接照抄的结论

1. **边的判据是两段式:候选 + 判定,不是任何单一信号。**
   A-MEM 先向量取最近邻当**候选**,再让 LLM 判"是否存在关系";HippoRAG 把**同义词边**交给向量阈值自动加。
   ⇒ **纯共现只能当候选,不能当边。** 我们的影子边(同记忆/同天共现)= 天然候选池,缺的正是第二段判定。

2. **失效的判据是"矛盾",不是"同槽"。**
   Graphiti:只在**语义相关且时间重叠的矛盾**上失效(且保留历史);Mem0:每条新事实显式选 ADD/UPDATE/DELETE/NOOP,只有矛盾才"以最新为准"。
   ⇒ 我们现在的 `slot = 源|关系`(同关系第二个目标顶掉第一个)是**把"唯一性"误当"矛盾"**。KARDS 被德美跳顶掉、记忆 313 被 315 顶掉,都属于这一类误杀。

3. **多值 / 多归属是一等公民。**
   A-MEM 明说一条记忆可同时属于**多个 box**;Graphiti 的失效是逐**事实**判的,不是逐槽位。
   ⇒ "喜欢玩"必须能同时挂 KARDS、德美跳、战地1、舞萌;**单值应当只留给真正的单值关系**(就读于/专业是/称呼)。

4. **层级不要手写本体;要分组就"算"出来,而且要在查询期用。**
   GraphRAG 用 Leiden 社群 + 每级摘要,层级是**算法产物**(互斥完备、可重算);LightRAG 干脆不做社群,理由之一是重建代价太高。
   ⇒ 他担心的"喜好/游戏 这个 hub 该不该建":**不该由 LLM 往盘上写分类边**,而应当(要么)查询期按共享关系分组,(要么)周期性跑社群检测产出一份**可随时重算的视图**。分组错了就重跑,盘上不留错。

5. **"同一件事里的多个概念"的正确形态是 n 元超边,不是两两配对边。**
   HyperGraphRAG 的论证:二元分解会**丢 n 元语义**、制造孤立边;它用「知识片段 = 一条超边 + 一句自然语言描述」来承载。
   ⇒ **我们要的东西其实已经有了**:`episodic_memory` 一行就是那条超边,`summary` 就是那句自然语言描述。联想该在**检索时**按"实体→记忆→实体"双向扩展(第 4 阶段 PPR 的入口),而不是把 48 条 pair 边铺进图里。这也正好解释了他说的"怎么连都合理"——**两两连本来就是信息损失**,所以怎么看都别扭。

## 3. 映射到我们这套表(现状 → 该改什么)

| 我们 | 现状 | 文献口径下的判断 |
|---|---|---|
| `graph_edges`(事实边) | 45 行,41 行挂 `用户`;`slot=源\|关系` 全单值 | **基数应逐关系声明**(多值:喜欢/喜欢玩/在意/想念/参加/会学;单值:就读于/专业是/是/称呼) |
| `graph_edges.is_active/superseded_by` | 写入即"同槽顶替" | 方向对(失效而非删除),**判据错**:应由矛盾判定驱动(LLM/规则),不应由槽位唯一性驱动 |
| `graph_shadow_edges`(48 条 pair 共现) | 只写不读,与事实边零重叠 | **不要**把它当"待晋升的边"。它的价值是**证据指针**(哪个记忆里有哪两个概念),形态应当收进超边模型 |
| `graph_aliases` / 重复节点 | 库里有 `西电`/`西安电子科技大学`、`大一学生`/`大一新生`/`大学生` 等重复 | HippoRAG 的**同义词边**(向量阈值)是标准解法:接起来而不是删掉 |
| `episodic_memory` | 一行 = 一条记忆(summary 天然含 n 元关系) | **就是超边本体**;联想检索(PPR/双向扩展)的入口在第 4 阶段 |
| 面板可视化 | 单星拓扑,看不出"同域" | "同域"是**查询期视图**:共享同一 `(源, 关系)` 或同一记忆的实体即可成簇 |

**明确不做**(三家都给了反证):不自动传递闭包(不因"都喜欢"就把 KARDS↔战地1 落成边)、不手写类别本体、不把共现直接写进事实边、不为分组而重建整图。

## 4. 建议的三步(按风险从低到高)

1. **修单值化(零新写入,立即见效)**:`slot` 改为 `源|关系|目标`(或按关系声明基数);episodic 的 `longTermInterests` 允许多条并存。⇒ KARDS 不再掉线,"喜欢玩"能列多个对象。
2. **影子边改为"只读证据视图"**:面板/检索只能把它当**候选来源**(指向记忆),并补上 A-MEM 的第二段判定(LLM 判"是否成边")。**仍然不进检索域**(红线不动)。
3. **第 4 阶段(只读 PPR)照 HippoRAG 做**:种子 = 向量命中的概念 + 记忆行;实体↔记忆双向扩展;LLM 只做"过滤无关"不做"发明关系"。这一步才真正让"同域联想"发生,且全部可重算。

> 一句话总结给他:**要的不是"把两个节点连起来",而是"让同一件事里的概念在检索时能互相找到"**——
> 文献的共识是:联想在**查询期算**(PPR / 双向扩展),盘上只留**有出处、可失效、可重算**的东西。

## 7. 十六份材料里的六条共识

1. **联想在查询期算,不在盘上铺概念↔概念的两两边。** PPR(HippoRAG 1/2)、时间邻近缓冲(EM-LLM)、双层关键词(LightRAG)、塌缩树(RAPTOR)、超边双向扩展(HyperGraphRAG)——**没有一家**把"概念两两相连"当作主机制。
2. **分组/层级一律"算出来",并且允许多归属。** Leiden(GraphRAG)、GMM 软聚类(RAPTOR)、模块度(EM-LLM)、概念图对齐(KAG);RAPTOR 与 A-MEM **都**明说"一个单元可同时属于多个组"。
3. **"换代/失效"只在矛盾时发生。** Graphiti(矛盾且时间重叠方置 `t_invalid`)、Mem0(ADD/UPDATE/DELETE/NOOP)、MIRIX("除非被概念性覆盖")。**没有一家**用"同槽唯一"作为失效判据。
4. **图变乱的两大根因是"没有类型"与"粒度不齐"**,KAG 直接把这两条写成噪声清单(多义、同义、词粒度、稀疏)。
5. **检索分是"近因 + 重要 + 相关"的加权**,遗忘是衰减 + 复述强化;我们已有的 `activation/half_life/intrinsic_value/recall_count` 正对应这一套(MemoryBank / Generative Agents)。
6. **记忆是分层组件,不是一张图。** MemGPT/Letta/MIRIX/LangMem 都把图当作**一个**组件(语义层),情景、程序性、核心记忆各自独立——这支持"别指望图谱一个人扛下全部联想"。
