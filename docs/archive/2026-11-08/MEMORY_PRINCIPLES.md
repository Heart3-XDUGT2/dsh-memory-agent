# 长程记忆检索:通用原则(证据版)

> **这份文件是"通用"的** —— 不针对任何特定语料、任何特定系统、任何本地读数。
> 全部结论来自 18 篇原始文献的**全文**;每个数字都标出处(arXiv 号),核不到的不写。
> 用途:给记忆检索/长程记忆系统的设计与评测当"总纲与判断尺"。
> 配套:`docs/RETRIEVAL_ARCH_NOTES.md`(逐篇笔记 + 证据索引表)。

---

## 0. 一句话

**长程记忆的收益主要来自"结构"——怎么组织上下文、什么时候写入什么、什么时候拒绝回答;
而不是来自"更强的语义匹配"** —— 后者在证据里反复是收益最小、最容易被高估的一环。

---

## 1. 误差是**三分**的(设计任何系统前先承认这件事)

| 层 | 含义 | 关键证据 |
|---|---|---|
| **①没取到** | 召回/覆盖不足 | 迭代检索只在这一层有效(2412.15266:K 有峰值,K=200 反而更差) |
| **②取到了没组织好** | 呈现/位置/顺序 | CPP(2608.?)H4:两个条件下 `Recall@k / Hit@k / MRR` **逐项相同**,答对率仍 **+3.4pp**;单项最大增益=**证据高亮 +26.3pp**,且**不多给一个字** |
| **③取到了也用错** | 利用/推理 | MemConflict(2605.20926)把错误**显式劈成**"检索失败 vs 利用失败",配白盒指标 SEH@3 / SRS |

**推论**:端到端准确率**不是召回率的单调函数**;只报 Recall/Hit 的评测看不见 ②③,
而 ②③ 恰恰是公开证据里**最大的增益来源**。

## 2. 八条原则(每条都有可迁移的机制与出处)

**P1｜分数必须先标定,阈值才有意义。**
病灶被明确指出:reranker 类分数**左偏堆在 0 附近**,生产上"阈值根本没法设"(MemReranker, 2605.06132)。
两处独立配方:z-score + sigmoid 后设 `τ`(MemX);取回段**最大相似度**低于阈值 ⇒ 抑制结果(CPP)。
**跨系统一致:先相对化,再截止。**

**P2｜"不回答"是一等能力,不是失败。**
MemX 规则 `K=∅ ∧ max sim < τ(≈0.50) ⇒ ∅`;CPP 把 **abstention** 单列一档评;
HaluMem(2511.03506)把 **FMR(假记忆抵御)** 列进抽取层指标。三处独立 ⇒ **拒答要被设计、被计量**。

**P3｜更新/矛盾/时间只能由**写入侧**编码,排序与迭代都代偿不了。**
TRACE(2607.00339):**类型化边**(temporal/causal/**update**/**contradiction**)+ **有效性标注**(失效边标 `v=0`,**不删**);
关掉即 **+0.314 → +0.212(−10.17pp)**。Zep(2501.13956):每条消息带 `t_ref`,**入库时**解相对/残缺日期,并**双时态失效**而非删除。
**反证**:SAGE(2605.12061)LongMemEval 零样本 **KU 23.5 / TR 13.8 / MS 9.4**,而单会话类 60~81 —— **换更强的图引擎也修不好这三类**。

**P4｜没有单一最佳粒度;要多粒度并存 + 按查询路由。**
MemGAS:多粒度 + **熵路由** `w_g ∝ 1/H_g` 胜过任一单粒度,且按问法分流(时间→会话级、知识更新→轮次级、偏好→摘要级);
CPP:段级胜过轮级("'听起来不错!'这类孤立轮几乎没有检索信号");HERO(2608.22310):Traces→Units→Cues 多层;
2412.15266:chunks/triples/atomic facts/summaries **混合**最好。

**P5｜压缩是有损的,必须可回溯到原文。**
HERO 明确反对 LLM 重写式摘要(不可逆信息损失 + 语义漂移),选择"忠实原文"的图;
CPP 只做抽句 + 高亮、**不改写**;LycheeMemory 用熵门控决定"哪里才压缩";
⚠️ 但要诚实:**"存储召回 0.671"意味着 32.9% 的问题在库里找不到原句**(CPP)——
压缩的代价要**当指标量**,不能假装置身事外。

**P6｜无界检索随深度退化;有界化/驱逐是精度手段,不只是省资源。**
CPP:k=15 时 **0.606 vs 无界 0.360(+24.6pp)**,归因于抽句先滤噪;容器**按构造有界**(400 段 FIFO)。
MemoryOS(2506.06326):三级存储 + **对话链 FIFO** + **Heat 分段页替换**。

**P7｜融合的收益取决于"两臂互补性",不取决于融合公式。**
RRF 在同类证据上被否;首选**分数级 z 归一融合**,**但在词面饱和语料上净增益小且不显著**;
cross-encoder 叠在融合 top-10 上 **−6.9pp Hit@1**。
⇒ **先测互补性(错误分解),再谈融合**;没有互补的两臂,融合公式再花也没用。

**P8｜顺序/位置本身是变量,U 型效应是真的。**
Lost in the Middle(2307.03172):相关信息的**位置**显著影响表现,呈 **U 型**——放头尾好、放中间差,
且**上下文越长越糟**,极端情况下**低于"不给上下文"的闭卷基线**。
Found in the Middle(2406.16008):**U 型注意力偏置**是机制,做**注意力标定**可把中间的信息找回来。
⇒ 呈现层的任何设计(重排、高亮、追加)都必须**显式控制位置**,并**量位置的敏感性**。

## 3. 被证伪 / 不该默认成立的假设

| 假设 | 状态 |
|---|---|
| "多召回了就会答得更对" | ❌ 召回层与呈现层可**完全解耦**(CPP H4) |
| "更大的 K / 更长上下文更好" | ❌ K 有峰值(K=200 更差);上下文越长位置效应越糟 |
| "换更强编码器/图引擎顺带修好更新与时间" | ❌ SAGE 是反证(KU/TR/MS 仍低) |
| "融合公式越花越好(RRF/加权)" | ❌ 饱和语料上≈不涨,甚至负增益 |
| "压缩能无损" | ❌ 存储召回 0.671;压缩代价必须计 |
| "机制在论文里说了有效就是有效" | ❌ 大量**设计主张无消融**(例:MemoryBank 的遗忘曲线机制**没有无记忆基线**,其表只是跨模型对比) |

## 4. 尚无答案的公开缺口(引用前必须知道)

1. **没有可比协议**:同一能力在不同论文的数字不可直接搬——SAGE 那张表自己声明"**不应被当作单一严格排行榜**"(按上报协议分组);
2. **预算不对齐**:CPP 自认"少 4.8× **单元**" ≠ "少字数",**同等 token 预算**的对比是它认的最大方法论缺口;
3. **饱和档无效**:CPP 的 adversarial 档 **0.998,连"无记忆"基线(C1)也是 0.998** ⇒ 该档不测记忆质量;
4. **白盒/黑盒未统一**:MemConflict 提了双协议,社区未收敛;
5. **代价侧普遍缺失**:写入期 schema/有效性标注/双时态的**构建成本**几乎没有系统报告(Zep 报了延迟与 token:见 `RETRIEVAL_ARCH_NOTES.md` §15.2)。

## 5. 判读与自检的六条规矩

1. **分母固定为金标条数** —— 不数"过滤/加闸后幸存的条目",否则过滤器会伪装成改进;
2. **只做同数据集、同金标、同批次的比较**;跨协议不排名;
3. **数字核不到就不引用** —— 碎片化的 HTML/PDF 表格**宁可放弃**,硬排必然错列;
4. **区分"量出来的增益"与"设计主张"** —— 后者必须标注"未量";
5. **每个机制都要有负控/消融** —— 关掉它应当回到基线;
6. **报失败分解**(没取到 / 没组织好 / 用错),不只报成功数。
