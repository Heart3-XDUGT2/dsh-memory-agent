## 一、三选一

### 甲 · 列表页 + 独立轮页（**建议选这个**）

`#/audit` 仍是「一行一轮」，右侧多一格**迷你流程缩略**（宽窄表时长、红块=失败，18px 高）；
点一行进入 `#/round/<key>`，那一屏**只有这一轮**：整页宽的流程图 + 图注 + 折叠的文字表。

- **一屏放多少**：轮页 1440 放 **8 步 = 988px（1.1 屏）**；若把步卡内距 8→6px、图注两行并一行，
  8 步可压到 **~900px 一屏放下**。390 上 8 步 ≈ **1120px = 1.3 屏**（滚一次到底）。
- **390 一步多高**：**78px** 的卡 + 12px 间隔；一步 3 行（阶段名 / 一句话 / 入·出），不裁字、不横滚。
- **8 步轮在 1440 的可用宽度**：**1176**（整页），节点列 **878**、时长尺 **236** ——
  比现在 L2 里那 878−192=**686** 宽了 28%，卡片能一行放下「阶段名 + 原始名 + 一句话」。
- **代价**：多一次跳转；返回时列表的滚动位置与筛选要记住（hash 返回即可，`state` 还在）。
- **列表页**：一屏 ~7 行（63px/行，含组头），右侧缩略让"这一轮有几步、哪步红"不点也看得见。

### 乙 · 上下同屏（目录 + 整页图，不跳页）

上面一条可滚目录（每轮一行），下面直接是选中那一轮的整页图。

- **一屏放多少**：目录 4 行 ≈ 174px + 8 步图 988px = **1162px ⇒ 一屏放不下**（差 262px）：
  要么目录压到 2 行（信息太少），要么图被切在第 5 步。
- **390**：目录 3 行 + 图 —— 一屏只看到图的前 2 步，**"整页"退化成"半页"**。
- **代价**：目录与图抢同一屏，两边都不够用；这正是现在 L2 的病（小块里塞结构）。

### 丙 · 全是图的长页（每轮一张图，自带折叠）

- **一屏放多少**：每轮 648px（7 步紧凑版）⇒ **一屏 1.3 轮**；141 轮 ≈ **110 屏**长页。
  首屏看不到"哪几轮值得看"，只能一路滚。
- **390**：一步 78px ⇒ 一轮 ≈ 900px ⇒ 一屏勉强 1 轮，滚到第 7 轮就迷路。
- **代价**：丢了「需要看 15」这个结论性视图；200 行平铺的翻版（只是把行换成了图）。

### 选甲，理由

1. **不挤**：1176 的整页宽是唯一能让 8 步图一屏放下的形态（乙 1162 溢出、丙 110 屏）。
2. **两个问题分给两屏**：「哪几轮值得看」留在列表（L0 的 15、chips、63px/行），
   「这一轮怎么走的」进轮页 —— 现在两件事挤在同一屏的 L2 里，谁也不够。
3. **可深链**：一轮一个地址（`#/round/<key>`），能发给别人、能刷新、能前进后退。

**放弃乙的代价**：少一次跳转；但代价是图永远被切一半。
**放弃丙的代价**：没有"一路看下去"的纵览；补法是列表页的迷你缩略（不点也能扫）。

## 二、整页宽之后，图怎么升级（用户点名的四件事）

| 现在（L2 里） | 整页后 |
|---|---|
| 步卡 686px 宽、3 行 | **卡 878px 宽**：一行放「序号 + 阶段名 + 原始名 + 标记」，第二行一句话，第三行「入 … · 出 …」——**保留模块卡**，不做"纯节点 + 悬浮补"：审计屏是要读的，不是要逛的；悬浮在 390 与键盘上都不可用 |
| 并行支只是上下两行 + 括号 | **真的并排**：整页宽有 878，两条支各占 **424px**，左右并列、同一条起跑横线、右端各标落定时刻；汇合处一条 1px 竖线接回主轴 |
| 传递缝是一行小字 | **带箭头的连线 + 标签**：主轴上一段 1px 竖线在标签处断开，标签 `10 条候选` 用 13px 深色、动词 `交给组装` 用浅色；并行段的两条支各有一条汇合箭头 |
| 8 步以上：10 步 + 「还有 N 步」 | **分段**：主流程 ≤8 步一屏画完；>8 步时按"她开口 / 检索 / 回应 / 记账"四段分块，块间一条 1px 分隔 + 段名（13px 灰），**不折叠、不截断**；轮外行单独一块「轮外记账」 |

时长编码不变：**等距步骤轴 + 对数时长条（1ms→2min）+ 条尾真实数值**；没有耗时**不画条**。

## 三、路由：`#/round/<key>` 能不能进现有 hash 路由

**读代码的结论：不能，今天就进不去。**

| 位置 | 现在的行为 |
|---|---|
| `app.js:19` `ROUTES` | 固定 id 表（`overview/emotion/talk/threads/memory/graph/audit/…`），每项 `{id,title,lead,wired}` |
| `app.js:719-722` `routeById` | 认不出的 id → 回落 `ROUTES[0]`（近况） |
| `app.js:818-840` `applyLocation` | 取 `hash.slice(2).split("?")[0]`（:827）；**只认 `ROUTES` 里的精确 id**（:828）；不匹配就 `history.replaceState(null,"","#/overview")`（:830-833） |
| `app.js:1029` | `window.addEventListener("hashchange", applyLocation)` ⇒ 刷新 / 前进 / 后退 都走同一条路 |
| `app.js:856` | `api.route(id)` 只拼 `#/<id>` 单段，没有第二段的空间 |

于是 `#/round/9515d152…` 今天会被静默改写成 `#/overview` —— 用户点了个链接却落到「近况」，这是最坏的一种坏。

**最小改法（3 处，不动屏内逻辑）**

1. `applyLocation`：把候选拆成段 `const parts = hash.slice(2).split("?")[0].replace(/\/+$/u,"").split("/")`；
   `parts[0] === "round"` 时 `id = "audit"`、`param = parts.slice(1).join("/")`（key 里可能有 `-`，不会再带 `/`）。
2. `ROUTES` 加一条 `{ id: "round", title: "这一轮", wired: true }`（屏自己渲染整页图），
   `activate(id, {focus, param})` 把 `param` 透给 `mount(root, api, param)`；返回列表用 `api.route("audit")`。
3. `api.route(id, tail)` → `tail ? \`#/${id}/${tail}\` : \`#/${id}\``。
4. **未知 key**（窗口滚过 200 行、或换了一台机器）：轮页渲染一句人话
   「本机窗口里没有这一轮（200 行 / 141 轮里没找到），可能是窗口滚过去了」+ 一颗「回列表」，
   **不空白、不报错、不改地址栏**（深链仍然成立，刷新还是同一句）。
5. 前进/后退/刷新不用改：`hashchange` 已接（:1029）；列表页的筛选与页码在 `state` 里，返回即恢复。

## 四、动效清单（只表达状态与先后）

| 时机 | 动作 | 时长/次数 |
|---|---|---|
| 进轮页 | 主轴自上而下用 `stroke-dashoffset` 画入（一条线在长） | 900ms ×1 |
| 同步 | 步卡与它的时长条**同一延迟**按步骤顺序淡入并上移 8px | 300ms，步进 **80ms** |
| 并行支 | 两支 `--i` 相同 ⇒ **同时**亮（不排队） | 同上一拍 |
| 汇合/失败 | 圆点外一圈 1px 环扩出去（汇合青、失败红） | **200ms ×1**，不循环 |
| 传递缝 | 标签在两侧步卡之后淡入 | 280ms，+180ms |
| 展开/收起（折叠的文字表、L3） | 只动 `opacity`，**不改高度** ⇒ 不留 CLS | **100ms**（反馈，不是装饰） |
| `prefers-reduced-motion: reduce` | 全部 `animation: none`、环 `opacity: 0`；图直接终态；展开/收起仍保留那 100ms | — |

**禁止**：循环播放、粒子、用位移表达时长、任何引起布局移动的动画（只用 transform/opacity）。

## 五、可访问性与兜底

1. **等价文字视图**：轮页里每个步卡下面的「看文字明细（表格）」折叠项 = 同一轮的同 N 行
   （序号/时钟/阶段/一句话/耗时/标记）；图形与表格由**同一份 `flowOf()` 数据**渲染，不可能对不上。
2. **读屏**：每个步卡是一颗按钮（`aria-expanded/aria-controls` 指向它那一行的 21 键表），
   `aria-label` 写完整一句（「第 2 步 情绪打分：并行支，失败，没留原因」）；
   主轴/刻度轨/括号是 `aria-hidden="true"` 的装饰。
3. **没有图形能力**（旧浏览器 / 打印）：`<svg>` 只画主轴，其余是 HTML —— 关掉 SVG 图仍然完整。
4. **不泄漏**：`C:\` / `session-[0-9a-f]{8}` / UUID / 原始 JSON 一律 0；`traceId`/`sessionId` 只在 L3 列键名。
5. **不造假**：没有的字段 `—`；`agentState` 照旧「轻量窗口下取不到」。

3. 把 200 行平铺成一屏（丙那样 110 屏的长页也不做）。
4. emoji、彩色状态灯、深色底、渐变、阴影。
5. 力导向图、粒子、循环动画、用位移或颜色亮度表达时长。
6. 改产品 `web/`、`lib/`、`web/audit-view.js`；改 `index.html` 的脚本顺序。
