# 长程记忆检索:分层架构设计(通用草案)

> **只写设计,不含实现;不绑定任何语料、任何具体系统。**
> 层序由 §2 的证据强度决定,不按"听起来先进"排。
> 与 `docs/MEMORY_PRINCIPLES.md` 配套:那边是原则,这边是把原则落成层与接口。

---

## 0. 设计立场

1. **先承认误差三分**(没取到 / 没组织好 / 用错),并为**每一层**准备独立指标;
2. **凡"过滤/加闸"类读数,分母固定为金标条数** —— 否则过滤器会伪装成改进;
3. **优先级 = 证据强度 × 代价**:呈现层证据最强、代价最小;检索臂改造证据最弱;
4. **每个机制都要能关掉**(负控),关掉回到基线才算数。

---

## 1. 层序(设计顺序 ≠ 实施顺序)

| 层 | 名称 | 依据 | 设计顺序 | **实施顺序** |
|---|---|---|---|---|
| **L1** | 写入侧状态编码(时间/有效性/类型/来源) | P3 | 1 | **3** |
| **L2** | 多粒度表示 + 查询路由 | P4 | 2 | 4 |
| **L3** | 标定 + 拒答 | P1 / P2 | 3 | **2** |
| **L4** | 呈现层(位置 / 高亮 / 顺序 / 预算) | P8 + 呈现证据 | 4 | **1** |
| **L5** | 检索臂(稀疏 / 稠密 / 融合 / 迭代) | P7 | 5 | 5(最后) |

**为什么 L1 在设计上排第一、实施上排第三**:它是唯一**不能被上层代偿**的东西(TRACE 关掉 −10.17pp;
SAGE 的反证),但它依赖 L4/L3 先把"能量出增量"的仪器建起来 —— 否则改了也看不见。

---

## 2. 逐层:接口 / 依赖 / 必须能测 / 负控 / 风险

### L4 呈现层(实施第一步)
* **做什么**:决定**哪些片段、以什么顺序、带什么标记**进入生成上下文。三种可独立开关的手段:
  (a) **位置控制**(相关证据放头/尾,避免落中段);(b) **证据高亮**(把最相关的那句标出来);(c) **段级 vs 轮级**的选择。
* **依据**:CPP 的 H4(召回指标逐项相同仍 +3.4pp)、高亮单项 **+26.3pp**、k=15 时 **+24.6pp**;
  U 型位置效应(2307.03172)与注意力标定(2406.16008)。
* **接口**:输入 = 已排好序的候选段 + 每段的最佳证据句;输出 = 定长上下文 + 位置标注。
* **依赖**:无(可在现有检索器之上加)。
* **必须能测**:位置敏感性(同一批证据打散位置后的表现差)、高亮开关的增量、**预算对齐**(同等 token)。
* **负控**:关掉高亮/位置控制应回到基线;位置随机化跑一遍,差应≈0。
* **风险**:**预算混淆** —— CPP 自认"少 4.8× 单元"≠"少字数"。**任何呈现层增益必须在同等 token 预算下复现**。

### L3 标定 + 拒答(实施第二步)
* **做什么**:把打分**相对化**(z-score + sigmoid 或等价),再设**截止 τ**;`max < τ ⇒ 判为该查询无命中`(整池清空)。
  拒答**单列一档**统计。
* **依据**:三处独立来源(MemReranker 的"未标定 ⇒ 阈值不可设";MemX 的 z+sigmoid 规则;CPP 的低置信度过滤)。
* **接口**:输入 = 候选打分分布;输出 = 校准后置信度 + `matched/abstained` 布尔 + 被拒原因。
* **依赖**:需要**每查询**的候选分布(不是一个全局阈值)。
* **必须能测**:拒答率(负控档)vs 误杀率(正样本档)的 ROC;以及**每档不退**的约束。
* **负控**:`τ = 0`(什么都不拒)必须**逐字复现**未加闸读数。
* **风险**:τ 必须在**同批金标**上定;样本太小时只能定"零成本区间",不能定单点。

### L1 写入侧状态编码(实施第三步,先做"切片"而非重写)
* **做什么**:写入时记录 (a) **参考时间戳**(把"下周/上次"解成绝对时间)、(b) **有效性区间**(失效是**标注**而不是删除)、
  (c) **边类型**(尤其 **update / contradiction**)、(d) **来源指针**(可回溯原文)。
  落法可轻:先给已有记录补元数据 + 一套**只增不删**的失效标记,不必一步到知识图谱。
* **依据**:TRACE(类型化边 + `v=0` 标注;关掉 **−10.17pp**)、Zep(`t_ref` 入库解相对日期;双时态失效)。
* **接口**:输入 = 原始交互;输出 = 带时间/有效性/类型/来源的结构化记录 + 写入成本。
* **依赖**:抽取质量(见下"必须能测"第 3 条)。
* **必须能测**:(1) 更新类问题上的正确率;(2) **矛盾**是否被识别而非共存;(3) **抽取层**指标
  (完整性 / 准确率 / 假记忆抵御) —— HaluMem 证明:三家抽取准确率 86–92% 看着都好,而**加权召回 14.55 ↔ 43.28 差三倍**,
  单一准确率会完全盖住失败;(4) **构建代价**(时间/token)。
* **负控**:把有效性标注关掉(退化成"都有效"),矛盾档应显著变差;反之若没变差 ⇒ 该机制在数据上没用。
* **风险**:**代价高且缺参照**(公开工作几乎都不报构建成本)⇒ 必须先量代价再决定投入。

### L2 多粒度表示 + 路由
* **做什么**:同一内容并存多种粒度(轮/段/摘要/事实/事件),**按查询类型路由**(或按熵加权)。
* **依据**:MemGAS 熵路由 `w_g ∝ 1/H_g` 优于任一单粒度;CPP 段级 > 轮级;HERO 多层 cues;2412.15266 混合最好。
* **必须能测**:路由是否真的按类型分流(路由决策的可解释统计)、每个粒度的分档表现。
* **负控**:把路由退化成"固定单粒度",增益应消失。

### L5 检索臂(最后)
* **做什么**:稀疏 / 稠密 / 融合 / 迭代深度 / reranker。
* **依据**:P7(融合收益取决于互补性);迭代只治召回型档(SAGE 的 KU/TR/MS 不动)、**K 有峰值**。
* **必须能测**:**两臂互补性**(错误分解:各自单独失败 vs 共同失败)、迭代轮次收益曲线(找峰值,别默认越深越好)。
* **负控**:关掉融合回到单臂;迭代轮次 +0 应回到单轮基线。
* **风险**:在**词面饱和**的语料上,融合与 reranker 的净增益可能≈0 甚至为负(cross-encoder 叠融合 top-10 **−6.9pp Hit@1**)。

## 3. 横切:仪器必须先于机制

没有这些,任何一层的"改进"都不可信:

1. **三分错误分解**(没取到 / 没组织好 / 用错),各自单独报;
2. **顺序/位置敏感度**:同一证据集合打散重排,报差异 —— 位置是变量,不是常数;
3. **拒答 ROC**:拒答率 vs 误杀率,并给"零成本区间";
4. **分母固定**:过滤类读数一律以金标条数为分母;
5. **负控**:每个机制的"关掉版"必须在同一批数据上跑;
6. **干扰项注入**:用语义相似但非目标的记忆做对抗(MemConflict 的做法),否则负控档太弱;
7. **饱和档剔除**:若"无记忆基线"也接近满分(CPP 的 adversarial 0.998),该档**不测记忆质量**,应删或换;
8. **预算对齐**:呈现/压缩类增益必须在**同等 token**下复现。

---

## 4. 明确"先不要做"的清单

* ❌ **不要在没测互补性之前上融合**(RRF/加权在同类证据上≈不涨);
* ❌ **不要默认加深迭代**(K 有峰值;迭代不治更新/时间);
* ❌ **不要把 K 或上下文窗口往大堆**(越大位置效应越糟);
* ❌ **不要用"设计主张"当验收标准**(没消融的机制一律标"未量");
* ❌ **不要在饱和档上刷分**(那种数字不动记忆质量);
* ❌ **不要把过滤器加闸后的均值当改进**(分母必须固定)。

## 5. 未决问题(需要数据才能答,不是靠推理)

1. **同等 token 预算下,呈现层的增益还剩多少?**(CPP 留的最大缺口)
2. **有效性标注/双时态的构建代价**,以及它在多大语料上才开始回本?
3. **矛盾识别**要靠结构化边,还是也能由抽取层提示词解决?两者代价差多少?
4. **路由**需要多准?路由错分时的代价有多大(是优雅退化还是崩)?
5. **拒答阈值**在多大金标上才可定死(小样本只能定区间)?
6. **什么条件下融合才开始有正收益**(互补性要到多高)?
