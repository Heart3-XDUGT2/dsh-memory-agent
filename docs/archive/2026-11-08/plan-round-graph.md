# 这一轮的流程图（P9A）· 设计说明

布局：横向线路图。一步一个 128×54 节点（序号/阶段名/一个词的状态），带进出端口，1.5px 连线加箭头；
并行支从「她起头」分叉成两条臂、在「检索」前汇合；轮外行压在最下虚线带。只印有真量的边，其余进悬停。

390：容器窄于 760 改竖向——节点竖排成 320 窄列、分叉左右并排、连线向下。

入口：悬停=跟鼠标的浮层（偏移 10px、贴边翻转）；Tab 逐个节点/连线、focus 同浮层、Esc 收；
点节点钉住，点空白收起。

时间轴：两条同宽、各自真实比例的带——整轮 83.1 秒与放大 ×11.2 的前 7.4 秒；每段最小 3px，印不下的时长挂引线；
最慢与失败在轴上点出，悬停与上方节点互亮。退路：看文字明细，21 键仍从每行进 L3。

## 已知取舍

1. **两条带而不是一条**：83 秒里 7 步只占 7.4 秒（8.9%），单条真比例轴上每个短步都是 3px、印不下字。
   下面那条是同一段真实时间的放大，倍率印在标题上 —— 不放大就只能"看见位置、看不见时长"。
2. **并行臂各占一行**：两条臂在同一段时间里重叠，挤一行会画成一条更长的条（那是在撒谎）。
3. **节点上一律只留一个词**：`失败 / 并行 / 轮外 / 慢` 或时长；其余（原始名、入出、失败原因）进浮层。
4. **768 也走竖向**：528px 的内容列放不下 7 列 96px 的节点（会裁字）。
5. **颜色只花在数据上，而且必须一直在**：连线是主色（1.25px、静止态 0.55 透明），时间轴的段也是主色；
   没有耗时、也没有连线的单行轮，段的 3px 也照画（轴标题写「没有跨度」）—— 否则整屏没有一个像素是数据色，
   `inspect` 的 `no-data-hue` 会亮。节点边框保持中性，只有失败那一步用 `--negative`。
