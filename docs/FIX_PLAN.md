## 一、取证结论

### 1. 章鱼小丸子为什么每轮都在 —— 它被"钉"在图里

全库 35 条边里 `layer='L0'` 的**只有 2 条**:

```
edge#3  用户 -[喜欢]->   章鱼小丸子   (iv=91.1, hl=190, recalled=94)
edge#27 <称呼> -[喜欢吃]-> <话题>   (iv=95.9, hl=471, recalled=54)
```

`python/engine/graph.py:539-542` 把 L0 边收进 `pinned`,`:653-654` 让它
**独占配额、不参与 top_k 竞争、永不被挤掉** ⇒ 每轮无条件注入,与他说什么无关。
22/22 条带注入的审计行全都是这两行,**逐字相同**。

### 2. 图侧为什么没有别的内容 —— BFS 每轮 0 条

种子三通道,三个全废:

| 通道 | 位置 | 实测 |
|---|---|---|
| ① 字面扫节点名 | `graph.py:487 direct_seed_hits` | 22/22 真实输入命中 `[]` |
| ② LLM 种子 | `worker.py:871` 读 `extraSeeds` | **从未接上**(见下) |
| ③ 机械 CJK 切分兜底 | `graph.py:419 extract_seed_nodes` | 切出 `'有什么想说的吗'`/`'QQ'`/`'——'`,全不匹配 |

通道②接错线:`lib/turn-snapshot.js:115-121` 传的 extras 是
`{ now, longingLine, emotionVector, shock, aliases }` —— **没有 `extraSeeds`**,
于是 `lib/engine.js:154` 的 `extraSeeds: extras.extraSeeds ?? null` 恒为 null,
`worker.py:871` 每次掉进机械兜底分支。

**反证**(实测真引擎):

| 输入 | 字面命中 | BFS |
|---|---|---|
| `我在西电上学,今天校园跑跑完了` | `['校园跑']` | **8 条** |
| `Echo 的记忆架构你想怎么改` | `['Echo']` | **8 条** |
| 审计里 22 条真实消息 | `[]` | **0 条** |

节点名只有:用户、Echo、聊天、她、<称呼>、章鱼小丸子、校园跑、新工科大学、
西安电子科技大学、3km速度限制、一千美元、大一学生、软件工程专业、浪费时间、
做章鱼小丸子。他的日常消息(`在吗`/`继续`/`吃了藤椒鸡排咖喱饭`)一个字都不含。

### 3. 情景记忆为什么每轮都是「风又音理」(#125) —— 同一类病

**17 条 L0 记忆里 16 条 `is_active=0`,只剩 `#125` 活着。**

```
被关的:#65 #90 #93 #128 #42 #45 #53 #87 #88 #39 #49 #92 #127 #130 #95 #126
幸存:#125 (唯一 active 的 L0)
```

`retrieve` 候选池硬性要求 `is_active=1`(`retrieve.py:199`),L0 又是**强制占位**
(`retrieve.py:167-176`)⇒ 每轮必进。

再叠加**写回强化**(`retrieve.py:226-239`,注释自称「与图侧 pinned 的豁免是
刻意的不对称」)⇒ `#125` 被强化 **2463 次**(第2名 #114=784,同层 #42/#53=110),
half_life 涨到 440h,R 恒 ≈0.999,**正反馈锁死**。

对照 `graph.py:536-537` 的注释,几乎是同一件事的镜像:

> pinned 不算「被想起」—— 调用方跳过它们,**否则每轮注入等于每轮强化**

**图侧防住了,记忆侧刻意没防。**

### 4. 整固(supersede)在毁数据

**(a) 16 条 `superseded_by` 指向不存在的记忆。**

```
#39/#42/#45/#49→431  #53→437  #65→411  #87→412  #88→416  #90→417
#92→419  #93/#95→445  #64→389  #70→399  #75→402  #78→418
```

`episodic_memory` 用 AUTOINCREMENT,`sqlite_sequence` = **256** = `max(memory_id)`,
而 AUTOINCREMENT 只增不减 ⇒ **id 257~445 从未存在过**。而且这 16 条的日期全在
**09-18 ~ 09-21**,之后(#126→127、#127→169、#128→169、#130→171)全部能解析
⇒ **A 侧迁移残留**:A 侧 DB 的 id 到了 445,迁移只搬 256 行,`superseded_by`
带着旧文件的 id 过来了。全库 50 行有 `superseded_by`,16 行悬空。

**(b) 幸存者丢掉 `layer` 和 `intrinsic_value`。**

| 幸存者 | layer | iv | 内容 |
|---|---|---|---|
| `#169` | `reflection`(不是 L0) | **0.0** | 用户喜欢吃章鱼小丸子 |
| `#171` | `reflection` | **0.0** | 用户想把Echo打造成自己心目中的样子 |

`#126→#127→#169`、`#128→#169` 合并了,但幸存者没继承 L0 层级和 iv
⇒ **L0 层被清空到只剩 1 条,幸存者 iv=0 永远进不了强制占位**。
