我们的病，**多数是"实现没做到"，不是"范式输了"**。

## 三条最值钱的发现

### 1. 最大的差距不是"检索不行"，是"模型不能自己多翻几次"

- Letta 把整段对话史塞进一个 `.txt`，让模型自己 `grep` / `open` / 反复找。
- 它在 LoCoMo 上拿 **74.0%**，**高于 Mem0 自报的图变体 68.5%**。
- Letta 自己说：这分数主要来自"模型被训练过会用文件工具"，不是记忆机制；并断言"**记忆更多取决于 agent 怎么管上下文，而不是具体检索机制**"。
- 我们的 `load()` 是**一轮注入就完事** ⇒ 我们根本没有"让 agent 自己迭代查"的通道。
- ⇒ **这是最大、也最好修的差距**（是"实现取向"，不是范式缺陷）。

### 2. "schema 写了等于没写"

- `node_type` **从来没被写入** ⇒ 所有"按类型分支"的逻辑**全部不可信**；`is_protected` **恒 0 = 死代码**。
- 别人两条最便宜的做法：
  - **写前校验 + 结构化拒绝** —— 拒绝要说清"违反哪条 + 允许什么值"。`dsh-ontology` 的真实返回：`REJECTED ada depends_on api: ...`。
  - **`committed` 式真值回执** —— 灵枢原话：「**别把 `ok:true` 当写成功**」，落盘只看 `committed`。
- ⇒ 我们缺的不是更多 schema，是**让 schema 真的生效**。

### 3. 遗忘的形状：不要"删"，要"打戳 + 冻结 + 版本链"

- 最便宜：**`valid_from` / `valid_until` 两列 + `supersedes` 类边 + 追加式更正** ⇒ 能回答"**上个季度我们以为是什么**"。
- 语义最对味：**MemOS** —— "**回滚走副本；权威冻结版本只读，不影响它的审计链**"。
- 我们目前**只有"30 天剪枝"**：没有选择性遗忘 / 冻结 / 软删 / 回滚 / 版本链。
- ⇒ 不动表结构就能补：**两列时间戳 + 一个软删列 + 一张版本表**。

## 三条别碰的 + 三个陷阱

| 别碰 | 为什么 |
|---|---|
| 参数化 / 权重式记忆 | 要训练、要改权重、要 GPU；还有"**可靠性 / 泛化性 / 局部性**不可能三角" ⇒ **整类排除** |
| 一切要常驻服务的 | MemGPT/Letta 原样要 Postgres；Memobase 要 FastAPI+Redis；Supermemory 是第三方云；honcho 没进程就没价值 |
| GraphRAG 式社区摘要 | 索引成本是全表最高一档，而且**没有 local 能力**（具体数字见 `PLAN_MEMORY_GRAPH.md` §2.3；SURVEY 未收录） |

| 陷阱 | 坑在哪 |
|---|---|
| Mem0 的"LLM 建链接" | 在它 OSS 里**根本没落库**（prompt 让它输出链接，ADD 路径只取 `text` / `attributed_to`） |
| A-MEM 的 links | 链接靠多步 LLM 生成 ⇒ 论文自陈"延迟与错误累积膨胀"；"单向 + 靠数组下标对齐"一说 **SURVEY 未收录，先别当依据** |
| Basic Memory | **AGPL-3.0** ⇒ **只能借思路，不能 vendor** |

## 为什么榜单别当真

- **MIRIX 85.38% / Letta 74.0% / Mem0 68.5% 三种口径不可比**：一个"只准看记忆"、一个"能反复翻原文"；长度口径 9K / 20K / 26K 三套；judge 是不是同一个——**未读到**。
- Letta 自己写了"**apples to oranges**"，并公开质疑 Mem0 那组跑分（Mem0 未回应）。
- **以后引用 LoCoMo 分数，必须同时说清五件事**：哪个版本 / 能否看原文 / 能否多轮检索 / 什么 judge / 实际判了多少样本。缺任一项即视为不可比。

## 我们要做什么

**先给结论：全部不需要推翻表结构。** 全是纯增列 / 纯增表 / 默认关 + 可回滚。**例外:`R-2` 的『文件成为 SSOT、SQLite 降级为索引』那一支会动现状,须单独裁决(`MEMORY_ARCH_SURVEY.md` §6 R-2)。**

| # | 做什么 | 图什么 |
|---|---|---|
| 0 | **只读测算** | 把"白送的路网"变成可复现的只读基线（时间边候选 216、同记忆共现 30→去噪 5、同天 94→42），后面每期都有对照 |
| 1 | **写入闸门 + 真值回执 + 补 `node_type`** | 让 schema 真的生效；拒绝有理由；写成功有真值回执；说话人节点不再灌噪声边 |
| 2 | **记忆工具化**（agent 可多轮调用） | 补上最大差距：让模型自己多翻几次，而不是一轮注入就完事 |
| 3a | **共现影子边** | 两个概念同现于一条记忆就落一条边 —— **零 LLM 调用** |
| 3b | **时间影子边**（需最小 `episode` 节点） | 给时序一个端点；节点做最小、只作端点，不进 L0 / 画像 / 人格注入通道 |
| 4 | **只读 PPR 扩散** | 让"查询→节点链接"承重（HippoRAG 2 里这条值 12.5 点）；纯图计算、零在线 LLM |
| 5 | **遗忘形状**（冻结 ≠ 删除） | 从"30 天剪枝"升级到"打戳 + 冻结 + 版本链"，能回答"上个季度我们以为什么" |
| 6 | **写权分离 + 离线巩固** | 把整理权从会话轮里摘出来交给离线子代理（已有 **7 个通道标签(2 个启动点)**）；产物**只增不删 · 可回滚 · 留痕** |
